# Atelier 6e · Déclic OS

Simulateur de bureau pour apprendre à utiliser la souris, les fenêtres et les fichiers en 6e. Le parcours s’utilise sans compte.

Pour jouer hors ligne, ouvrir `Declic-OS.html` dans un navigateur. Sur Mac, `Lancer-Declic-OS.command` ouvre le site sur `http://localhost:4183/`.

Les sources sont dans `src/`. `python3 src/build.py` régénère le HTML autonome. GitHub Actions construit et publie le site lors d’un push sur `main`.
